# Sample portraits

`demo-original.png` and `demo-beard.png` are fictional adult player assets for the app UI concept, created with the built-in image-generation tool. They are not extracted from a game save.

Original prompt: Create a square photorealistic portrait of a fictional male adult Portuguese football player, age 23, short dark curly hair, clean shaven, natural brown eyes, plain navy jersey without a logo, neutral expression, centered head and upper shoulders, soft studio lighting, warm gray background, no text or watermark.

Edit prompt: Edit the provided portrait. Change ONLY add a neatly groomed short dark beard and matching moustache following the existing jawline. Preserve the exact person, identity, facial proportions, eyes, eyebrows, nose, mouth, ears, hair, skin tone, pose, expression, jersey, framing, lighting and gray background. Do not age, beautify or reframe. Everything outside the facial-hair area should remain visually unchanged.

The model edit is illustrative and has not been proven pixel-identical outside the edited area. Production localized editing should preserve source pixels outside a reviewed mask.

Small JPEG copies embedded in the UI concept are display encodings of these images. The original PNGs are retained.
